# PRD：海外暂存与海外中转单本次修改说明

## 1. 文档范围

| 项目 | 内容 |
| --- | --- |
| 版本 | V1.0 |
| 日期 | 2026-07-17 |
| 状态 | 已实现并发布 |

本文只描述本次已经修改并上线的内容，不重复说明原有页面、状态流转或未改动功能。

## 2. 左侧导航调整

在“海外中转单管理”菜单下调整子菜单顺序：

1. 海外暂存
2. 海外中转单
3. 海外仓拦截
4. 指令管理

调整仅影响展示顺序，不改变原有页面入口、路由或权限。

## 3. 海外暂存

### 3.1 新增标识字段

| 状态页签 | 新增展示字段 |
| --- | --- |
| 暂存 | 入仓号、Shipment ID、Reference ID |
| 暂存已完成 | 入仓号、Shipment ID、Reference ID |
| 运输中 | Shipment ID、Reference ID |

上述字段在对应订单详情中展示；运输中列表不展示入仓号。

### 3.2 新增查询能力

海外暂存查询区新增以下输入框：

| 查询字段 | 查询方式 |
| --- | --- |
| 入仓号 | 单个输入、包含匹配（模糊查询） |
| Shipment ID | 单个输入、包含匹配（模糊查询） |
| Reference ID | 单个输入、包含匹配（模糊查询） |

查询条件与列表数据联动；重置操作同时清空三个字段。

## 4. 海外中转单

### 4.1 标识字段与查询

海外中转单各状态页签新增并展示以下字段：

- 入仓号
- Shipment ID
- Reference ID

查询区同步增加以上三个输入框，均支持单个输入和包含匹配（模糊查询）。

### 4.2 已确认状态字段调整

“已确认”状态的列表中删除以下字段：

- 快递单状态
- 快递单号

“创建快递单”功能保持不变；快递单相关信息不再作为已确认列表字段展示。

### 4.3 指令费用与核销状态

海外中转单全部状态页签新增“指令费用”和“核销状态”。

| 项目 | 规则 |
| --- | --- |
| 指令费用来源 | 关联子单新增的操作指令费用 |
| 核销状态 | 已核销、未核销、部分核销 |
| 已核销费用颜色 | 绿色 |
| 未核销费用颜色 | 黄色 |
| 部分核销费用颜色 | 蓝色 |
| 核销状态查询 | 下拉选择已核销、未核销或部分核销 |

新创建的海外中转子单默认核销状态为“未核销”。

### 4.4 是否到达海外仓

在“入仓时间（海外仓）”前新增“是否到达海外仓”字段。

| 状态页签 | 列表展示 | 查询 | 详情展示 |
| --- | --- | --- | --- |
| 待确认 | 是 | 是 | 是 |
| 已确认 | 是 | 是 | 是 |
| 已下单 | 是 | 是 | 是 |

字段取值为“是”或“否”。新创建的海外中转子单默认值为“否”。

### 4.5 已确认状态的确认下单校验

“已确认”页签中的操作按钮由“下单确定”调整为“确认下单”。

点击“确认下单”时，按以下顺序执行校验：

1. **核销状态校验**
   - 当所选运单中存在“未核销”或“部分核销”的指令费用时，弹出“存在待核销费用”确认框。
   - 提示文案：所选运单中包含未核销或部分核销的指令费用，是否仍要下单？
   - 点击“暂不下单”：终止操作，运单保持已确认。
   - 点击“仍要下单”：继续下一项校验或执行下单。

2. **海外仓到达校验**
   - 当所选运单中有货物“未到达海外仓”时，弹出“货物尚未到达海外仓”确认框。
   - 点击“暂不下单”：终止操作，运单保持已确认。
   - 点击“仍要下单”：确认下单，运单流转至已下单。

当两项校验均不触发时，系统直接完成确认下单。

## 5. 数据与页面联动

| 触发场景 | 默认数据 |
| --- | --- |
| 海外暂存创建海外中转子单 | 核销状态：未核销；是否到达海外仓：否 |
| 核销状态展示 | 列表核销状态、指令费用颜色和核销状态查询使用同一状态数据 |
| 到仓状态展示 | 待确认、已确认、已下单的列表、详情和查询使用同一到仓状态数据 |

## 6. 验收标准

1. 海外暂存各指定状态可查看对应新增标识字段，并可通过三个新增查询字段筛选。
2. 海外中转单各状态可查看入仓号、Shipment ID、Reference ID，并支持包含匹配查询。
3. 已确认状态不再显示快递单状态和快递单号。
4. 指令费用颜色与核销状态匹配，核销状态可筛选。
5. 待确认、已确认、已下单均显示并可筛选“是否到达海外仓”。
6. 已确认状态点击“确认下单”时，未核销/部分核销和未到海外仓校验均可阻止下单；逐项确认后才允许进入已下单。
