# 意向客户管理 PRD

## 1. 背景

当前系统已有正式客户管理页面，但缺少正式开户前的意向客户承接入口。业务需要先维护潜在合作客户，再根据合作进展发起开户，将意向客户带入正式客户的新建流程。

本需求新增“意向客户”页面，并补充其与“客户”页面之间的开户和询价记录关联。

## 2. 目标

- 在账号设置中新增“意向客户”页面。
- 支持意向客户新增、编辑、查询、导出、查看日志。
- 支持意向客户维护询价记录。
- 支持从意向客户发起开户，打开客户页面的新建客户抽屉。
- 客户页面查看/编辑时展示询价记录，并按模式控制是否允许添加。

## 3. 菜单入口

路径：`管理 / 账号设置 / 意向客户`

要求：

- “意向客户”入口放在“客户”入口上方。
- 点击后进入意向客户列表页。

## 4. 意向客户列表

### 4.1 列表字段

| 字段 | 说明 |
| --- | --- |
| 客户编码 | 系统自动生成，规则与正式客户编码一致 |
| 公司名称 | 意向客户公司名称 |
| 业务代表 | 负责该意向客户的业务人员 |
| 最近询价单号 | 当前意向客户最近一次询价的询价单号 |
| 最近询价时间 | 当前意向客户最近一次询价时间 |
| 询价次数 | 当前意向客户累计询价次数 |
| 创建时间 | 意向客户创建时间 |
| 操作 | 询价记录 / 编辑 / 发起开户 |

### 4.2 查询条件

| 查询项 | 关联字段 |
| --- | --- |
| 客户编码 | 客户编码 |
| 公司名称 | 公司名称 |
| 业务代表 | 业务代表 |
| 最近询价单号 | 最近询价单号 |

### 4.3 顶部操作

按钮位于列表左上角：

| 按钮 | 功能 |
| --- | --- |
| 新增意向客户 | 打开新增意向客户表单 |
| 导出 | 导出当前列表数据 |
| 查看日志 | 查看意向客户页面操作日志 |

列表右上角保留与客户页面一致的表格列设置按钮。

## 5. 新增意向客户

### 5.1 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| 公司名称 | 输入框 | 是 | 输入意向客户公司名称 |
| 业务代表 | 下拉单选 | 是 | 选择负责该客户的业务代表 |

### 5.2 业务规则

- 新增时不展示客户编码字段。
- 客户编码由系统自动生成。
- 客户编码规则与客户页面正式客户编码保持一致，例如：`SZ003764`。
- 客户编码是唯一标识，不允许人工修改。
- 公司名称和业务代表必填。

## 6. 编辑意向客户

编辑页面与新增保持一致。

| 字段 | 类型 | 是否必填 | 是否可编辑 |
| --- | --- | --- | --- |
| 公司名称 | 输入框 | 是 | 是 |
| 业务代表 | 下拉单选 | 是 | 是 |

规则：

- 编辑时不展示客户编码字段。
- 不允许修改客户编码。
- 公司名称和业务代表必填。

## 7. 意向客户询价记录

### 7.1 入口

在意向客户列表操作列点击 `询价记录`。

### 7.2 字段

| 字段 | 说明 |
| --- | --- |
| 询价号 | 询价单号 |
| 询价人 | 当前业务代表 |
| 询价时间 | 添加询价记录的时间 |

### 7.3 手动添加

支持手动录入询价单号，并加入当前意向客户。

校验规则：

- 询价单号不能为空。
- 询价单号不可重复。

添加成功后：

- 新增一条询价记录。
- 更新列表的最近询价单号。
- 更新列表的最近询价时间。
- 当前意向客户询价次数 +1。

## 8. 发起开户

### 8.1 入口

在意向客户列表操作列点击 `发起开户`。

### 8.2 页面流转

点击后：

- 切换到“客户”页面。
- 打开客户页面的“新建客户”右侧抽屉。
- 使用与客户页面点击“新建”完全一致的页面结构。

### 8.3 数据带入

| 客户页面字段 | 数据来源 |
| --- | --- |
| 客户名称 | 意向客户公司名称 |
| 认证资料-公司名 | 意向客户公司名称 |
| 销售代表 | 意向客户业务代表 |
| 备注 | `由意向客户 {客户编码} 发起开户` |

规则：

- 客户页面保存时生成正式客户编码。
- 意向客户编码不直接作为正式客户编码。
- 客户名称和备注不能为空。

## 9. 客户页面关联

### 9.1 新建客户

触发方式：

- 客户页面点击 `新建`。
- 意向客户页面点击 `发起开户`。

规则：

- 打开客户页面新建客户抽屉。
- 不展示询价记录模块。
- 保存后新增正式客户。

### 9.2 查看客户

客户列表点击 `查看`。

规则：

- 打开与新建客户一致的右侧抽屉。
- 基础信息、认证资料、联系信息、对接信息均只读。
- 在“对接信息”下方展示“询价记录”。
- 查看模式只能查看询价记录，不允许新增询价记录。

### 9.3 编辑客户

客户列表点击 `编辑`。

规则：

- 打开与新建客户一致的右侧抽屉。
- 客户信息可编辑并保存。
- 在“对接信息”下方展示“询价记录”。
- 编辑模式允许手动添加询价记录。
- 添加询价记录时，询价人取当前客户销售代表。

## 10. 客户询价记录

字段与意向客户询价记录一致。

| 字段 | 说明 |
| --- | --- |
| 询价号 | 询价单号 |
| 询价人 | 当前客户销售代表 |
| 询价时间 | 添加询价记录的时间 |

模式控制：

| 页面模式 | 是否展示询价记录 | 是否允许添加 |
| --- | --- | --- |
| 新建客户 | 否 | 否 |
| 查看客户 | 是 | 否 |
| 编辑客户 | 是 | 是 |

校验规则：

- 询价单号不能为空。
- 询价单号不可重复。

## 11. 状态说明

当前版本意向客户页面不展示状态栏。

后续如需扩展，可使用以下状态：

| 状态 | 含义 |
| --- | --- |
| 意向中 | 已创建，尚未发起开户 |
| 开户审核中 | 已提交开户资料 |
| 已开户 | 已转正式客户 |
| 已失效 | 确认暂不合作 |

## 12. 验收标准

### 12.1 意向客户页面

- 账号设置中存在“意向客户”菜单，且位于“客户”上方。
- 列表字段包含客户编码、公司名称、业务代表、最近询价单号、最近询价时间、询价次数、创建时间、操作。
- 查询条件包含客户编码、公司名称、业务代表、最近询价单号，并能关联对应字段。
- 新增意向客户只展示公司名称、业务代表。
- 新增时自动生成客户编码。
- 编辑意向客户不展示客户编码字段。
- 公司名称和业务代表必填。
- 业务代表为下拉单选。
- 询价记录支持查看和手动添加。
- 添加询价记录后，最近询价单号、最近询价时间、询价次数同步更新。
- 列表支持导出、查看日志、表格列设置入口。

### 12.2 客户页面关联

- 意向客户点击“发起开户”后，能打开客户页面新建客户抽屉。
- 发起开户时客户名称、认证资料公司名、销售代表、备注正确带入。
- 客户页面点击“查看”打开与新建一致的抽屉，字段只读。
- 客户查看模式下展示询价记录，但不能新增。
- 客户页面点击“编辑”打开与新建一致的抽屉，字段可编辑。
- 客户编辑模式下展示询价记录，并允许新增。
- 客户新建模式不展示询价记录。
