## 2. 产品定位

| 模块 | 核心对象 | 产品职责 |
| --- | --- | --- |
| 海外暂存 | 头程母单、在仓货箱 | 查看库存和库龄，选择可用箱，填写地址和指令，创建中转子单 |
| 海外中转单 | 中转子单、快递单、转单号 | 确认、打单、下单、出运、签收、取消、回退、费用和轨迹管理 |

对象关系：

    头程母单 1 ── N 货箱
    头程母单 1 ── N 海外中转子单
    海外中转子单 1 ── N 货箱
    海外中转子单 1 ── N 快递单／转单号／轨迹／费用／附件／事件

核心原则：

1. 箱号是库存占用和拆单的最小粒度。
2. 同一箱号同一时刻只能属于一张有效中转子单。
3. 头程运单号、中转子单号、快递单号和承运商转单号必须分开。
4. 子单取消后按原箱号回流原母单，不能只增加一个数量。
5. 所有状态动作必须由后端状态机执行并产生审计事件。

## 4. 端到端业务流程

1. 头程系统同步母单、客户、FBA、柜号、提单号、预报箱数和服务。
2. WMS 回传实收入仓、箱号、重量、尺寸、入仓时间和仓租起算时间。
3. 母单进入“暂存”，货箱进入“可用”。
4. 操作员从海外暂存选择母单，勾选一个或多个可用箱。
5. 填写目的国家、下单类型、收件地址和操作指令。
6. 系统原子创建中转子单，并将所选箱从可用改为已分配。
7. 子单进入海外中转单“待确认”。
8. 待确认可确认或取消；取消后箱号回流母单。
9. 已确认可创建快递单；创建快递单后子单仍停留在已确认。
10. 执行“下单确定”后进入已下单并记录下单时间。
11. 仓库维护承运商、箱级转单号和交接附件。
12. 校验通过后出运，进入转运中并记录出仓时间。
13. 系统或人工持续写入承运轨迹。
14. 完成签收并回传 POD，子单进入签收。
15. 母单全部箱均已物理出库或关闭后进入暂存已完成。

跨页面联动：

| 事件 | 海外暂存 | 海外中转单 |
| --- | --- | --- |
| 创建子单 | 可用箱减少、已分配箱增加 | 待确认新增子单 |
| 待确认／已确认取消 | 原箱号回流可用 | 子单进入取消 |
| 下单确定 | 库存不变 | 进入已下单 |
| 出运 | 在仓箱减少 | 进入转运中 |
| 签收 | 无新增库存影响 | 进入签收 |
| 全部箱出库／关闭 | 进入暂存已完成 | 保留完整历史 |

## 5. 状态流转

### 5.1 海外暂存

| 状态 | 含义 | 可执行动作 | 下一状态 |
| --- | --- | --- | --- |
| 运输中 | 未完成海外仓实收入库 | 查看、预录草稿 | 暂存 |
| 暂存 | 已入仓且仍有在仓箱 | 下单、导出、日志 | 暂存已完成 |
| 暂存已完成 | 全部箱已物理出库、退回或关闭 | 查看、导出、日志 | 有箱回流时重新打开为暂存 |

正式规则：运输中不可真正提交子单和扣库存。

### 5.2 海外中转子单

正向流：

    待确认 → 已确认 → 已下单 → 转运中 → 签收

取消流：

    待确认 → 取消
    已确认 → 取消

回退流：

    已下单 → 已确认
    转运中 → 已下单
    签收   → 转运中

### 5.3 状态动作矩阵

| 当前状态 | 动作 | 目标状态 | 前置条件 | 时间字段 | 库存影响 |
| --- | --- | --- | --- | --- | --- |
| 暂存 | 选择箱并提交 | 待确认 | 箱可用、地址完整 | createdAt | available 转 allocated |
| 待确认 | 确认 | 已确认 | 资料校验通过 | confirmedAt | 无 |
| 待确认 | 取消 | 取消 | 原因、二次确认 | cancelledAt | allocated 回流 available |
| 已确认 | 创建快递单 | 已确认 | 打单资料通过 | expressCreatedAt | 无 |
| 已确认 | 下单确定 | 已下单 | 快递单或承运委托成功 | orderedAt | 无 |
| 已确认 | 取消 | 取消 | 原因、二次确认 | cancelledAt | allocated 回流 available |
| 已下单 | 出运 | 转运中 | 承运商、转单号、交接资料 | outboundAt | allocated 转 outbound |
| 已下单 | 回退 | 已确认 | 权限、原因、二次确认 | 清除 orderedAt | 无 |
| 转运中 | 签收 | 签收 | 签收时间；按配置校验 POD | signedAt | 无 |
| 转运中 | 回退 | 已下单 | 权限、原因、撤销出库确认 | 清除 outboundAt、signedAt | 进入人工对账或恢复占用 |
| 签收 | 回退 | 转运中 | 管理权限、原因、二次确认 | 清除 signedAt | 无 |

轨迹状态与业务状态分开保存。手工新增“异常”或“已签收”轨迹不得越权覆盖业务状态。

## 8. P02 中转下单抽屉

### 8.1 打开条件

- 母单处于暂存；
- 存在 available 箱；
- 用户拥有客户和仓库权限；
- 母单未冻结或关闭。

### 8.2 顶部摘要

头程运单号、FBA 单号、柜号、提单号、客户简称、目的国家、服务、客户备注、海外仓备注、可下单箱数。

### 8.3 收件地址字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 下单类型 | 是 | FBA、Walmart、TikTok、私人地址 |
| 目的国家 | 是，产品补充 | 决定邮编、电话和打单校验 |
| 仓库代码 | 平台仓必填 | 转大写；命中地址簿自动带出地址 |
| 邮编 | 是 | 按国家格式校验 |
| 收件人 | 是 | 地址簿可带出 |
| 电话 | 私人地址必填 | 按国家格式校验 |
| 城市 | 是 | 不允许空白 |
| 州／省 | 按国家必填 | 与国家联动 |
| 公司 | 否 | 最大 100 字符 |
| 地址详情 | 是 | 最大 100 字符 |
| 客户备注 | 否，产品补充 | 最大 500 字符 |
| 海外仓备注 | 否 | 最大 500 字符 |

仓库代码命中地址簿时，自动回填邮编、收件人、城市、州和地址详情。手工修改需保存来源和修改日志。

### 8.4 货箱及商品字段

汇总：已选箱数、总实重、总体积、申报币种、总申报价值、材质／敏感属性。

材质选项：带磁、带电、纺织品、玻璃制品、普货、玩具、FDA 产品、成人用品、木制品、钢铁铝类、冲突类、电子类、灯类、自行车类、粉末、液体、敏感货、木制品非报关件。

箱级列表字段：

- 勾选、箱状态、锁定人／锁定时间；
- FBA／IBR 箱号、PO Number；
- 产品英文名、中文名；
- 申报单价、数量、总价；
- 材质、海关编码、用途、品牌、型号；
- 图片链接、销售链接；
- 箱重、长、宽、高。

勾选规则：

1. 只有当前母单的 available 箱可选；
2. 已分配、已出库、异常或他人锁定箱不可选；
3. 全选只选择当前可用箱；
4. 并发冲突时整单失败，不允许部分创建；
5. 提交失败保留地址和未冲突选择草稿。

### 8.5 操作指令

主表字段：费用名称、费用类型、计费单位、计费单价、计费数量、币种、总价、添加时间、添加人、描述、操作。

功能：新增、编辑、删除；总价自动计算；新增默认追加，不能无提示覆盖原有指令。

### 8.6 按钮与校验

| 按钮 | 规则 |
| --- | --- |
| 保存草稿 | 产品补充；保存地址和指令，不长期占用库存 |
| 提交 | 创建待确认子单并分配箱 |
| 取消／关闭 | 有未保存内容时提示并释放短时箱锁 |

提交校验：

- 至少选择一个箱；
- 箱属于当前母单且仍为 available；
- 母单版本未变化；
- 下单类型、国家、地址必填项完整；
- 私人地址电话完整；
- 服务和目的地组合有效；
- 数量、单价、尺寸格式正确；
- 敏感属性不与服务限制冲突；
- 请求携带幂等键。

## 21. 库存与数据一致性

数量定义：

| 字段 | 定义 |
| --- | --- |
| totalCount | 最终实收总箱数，拆单时不减少 |
| inventoryCount | 当前物理在仓箱数 |
| availableCount | 可创建新子单箱数 |
| lockedCount | 短时占用箱数 |
| allocatedCount | 已分配、未出库箱数 |
| exceptionCount | 在仓异常箱数 |
| outboundCount | 已物理出库箱数 |

关系：

    inventoryCount = availableCount + lockedCount + allocatedCount + exceptionCount

创建子单、取消和出运必须在数据库事务中同时更新母单、箱、子单关联和事件日志，并使用行锁或乐观锁。

所有写接口必须携带身份令牌、幂等键、期望版本、请求号；取消、回退、人工修正必须携带原因。

## 22. 异常机制

首期采用“主状态＋异常标记”，避免状态爆炸：

| 字段 | 说明 |
| --- | --- |
| 是否异常 | exceptionFlag |
| 异常类型 | 地址、库存、费用、打单、仓库、承运、轨迹、签收 |
| 异常等级 | 提醒、阻断、严重 |
| 责任人 | 当前处理角色／用户 |
| 处理状态 | 待处理、处理中、已解决、已关闭 |
| 原因 | 异常描述 |
| SLA | 最晚处理时间 |

阻断异常未解决前，不允许确认、下单、出运或签收。

## 23. 通用异常处理

| 场景 | 产品处理 |
| --- | --- |
| 箱号被占用 | 返回占用子单、操作人和时间；刷新并保留草稿 |
| 地址缺失 | 精确定位字段，不创建子单 |
| 私人地址无电话 | 阻止提交 |
| 母单版本变化 | 提示库存变化，刷新箱列表 |
| 打单部分失败 | 逐单展示结果；成功单不可重复创建 |
| 转单号重复 | 阻止保存并提示原绑定单 |
| 出运资料不全 | 列出缺失项，阻止出运 |
| 轨迹倒序 | 保存原始事件并进入异常队列 |
| 附件过大／类型不符 | 上传前后双重拦截 |
| 重复点击 | 返回首次成功结果 |
| 库存对账不平 | 冻结母单并创建异常任务 |

## 25. 验收标准

### 25.1 暂存拆单

- 6 箱母单选择 2 箱后，子单只包含这 2 箱；
- totalCount 仍为 6，availableCount 从 6 变 4，allocatedCount 从 0 变 2；
- 其余 4 箱可继续创建子单；
- 同箱并发提交仅一个成功；
- 刷新后关系仍存在；
- 重复点击不生成重复子单。

### 25.2 取消回流

- 待确认／已确认取消后，原箱号回到原母单；
- 回流数量与箱号集合一致；
- 重复取消不重复加库存；
- 原母单已完成时，有箱回流后重新进入暂存；
- 原因、操作者、箱号和请求号可查。

### 25.3 履约

- 只有待确认可确认；
- 只有已确认可下单确定；
- 创建快递单不自动改变中转状态；
- 出运前承运商和转单号必填；
- 只有转运中可签收；
- 生命周期时间随动作写入并在回退时正确清理；
- 签收可查看 POD 和完整轨迹。

### 25.4 页面

- 所有查询字段真实过滤；
- 列表、详情、导出口径一致；
- 私人地址电话、地址长度、邮编真实校验；
- 取消状态按权限只读；
- 搜索、分页、导出、附件和日志刷新后仍有效；
- 无权限用户无法通过直接接口执行动作。

## 26. 当前原型差距与优先级

### P0

1. 当前动态数据仅在前端内存，刷新即丢失；
2. 运输中也能下单；
3. 创建子单错误减少 totalCount 和 inventoryCount；
4. 可用箱归零不会自动判断暂存完成；
5. 货箱为固定模拟数据，无真实 WMS 来源；
6. 全选存在重新选中已移除箱号风险；
7. 头程单号和中转单号存在重复拼接风险；
8. 多数搜索、分页、导出仅为展示；
9. 出运未校验承运商和转单号；
10. 无事务、并发锁、幂等、持久化和后端权限。

### P1

1. 私人地址电话标记必填但未真实校验；
2. 地址字数只有计数，无长度限制；
3. 操作指令无数值和重复校验；
4. 暂存完成详情使用模拟地址；
5. 取消和回退无原因及审批；
6. 转单号无重复占用校验；
7. 取消详情仍可修改部分业务信息；
8. 状态日志不是完整事件流；
9. 缺少异常任务、责任人和 SLA；
10. 页面无独立 URL、深链和刷新恢复。

### P2

表头个性化、批量导入、智能地址校验、仓租预警、自动承运路由、客户自助轨迹和经营看板。
